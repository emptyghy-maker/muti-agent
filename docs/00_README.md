## 一、产品一句话描述

用户选定目的地（首期：南京、苏州）后，首轮自由表达旅行想法，系统通过「缺口分析 + 分步按钮问询」收集偏好（**绝不重复提问**），生成**景点、美食、酒店三级候选集**供确认，再生成**按天的行程规划**（操劳程度联动 + 饭点约束 + 休息点 + 预计消费 + 天气提醒）；行程**持久化保存、可局部修改**，所有地点支持点击查看「上一地点 → 该地点」的具体路径；用户评价反馈回流驱动系统迭代优化。

## 二、核心业务流程（一图流）

```
选目的地（南京/苏州）
  → 开场白 + 首轮自由输入（引导提示词）
  → 缺口分析：只追问缺失项（分三批优先级，按钮快捷回复，绝不重复问）
  → 生成景点候选集（名称+特色）      → 用户确认（regenerate ≤2 次）
  → 生成美食候选集（风味→店铺集合）  → 用户确认
  → 依据已选点生成酒店候选集（名称+金额+评分） → 用户确认
  → 按天规划路径（操劳程度前后天联动 + 饭点约束 + 休息点 + 预计消费 + 天气提醒）
  → 行程落库（我的行程列表，刷新不丢；可 ADJUST 局部修改，版本链）
  → 地点超链接 → 查看上一地点到该地点的具体路径方案
  → 用户评价（评分/标签/评论 + 隐式信号）→ 反馈数据驱动迭代优化
```
