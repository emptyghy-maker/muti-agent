# 04 数据模型设计

> 库：沿用 `data_agent`（192.168.150.105 的 da-mysql）；业务表前缀 `t_`；中文用 utf8mb4，种子数据建议 UNHEX 十六进制写入防乱码（旧项目经验）。

## 1. 表设计（DDL）

### t_destination 目的地
```sql
CREATE TABLE t_destination (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(64) NOT NULL,             -- 城市名，如 南京
  province VARCHAR(64),                  -- 省份（首期：江苏）
  intro VARCHAR(512),                    -- 一句话介绍
  tags VARCHAR(255),                     -- 标签，逗号分隔：美食/自然/人文/亲子
  daily_budget_min DECIMAL(10,2),        -- 人均日消费参考下限（默认预算计算用）
  daily_budget_max DECIMAL(10,2),        -- 人均日消费参考上限
  status TINYINT NOT NULL DEFAULT 1
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### t_attraction 景点
```sql
CREATE TABLE t_attraction (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  destination_id BIGINT NOT NULL,
  name VARCHAR(128) NOT NULL,
  category VARCHAR(32) NOT NULL,         -- 打卡拍照 / 娱乐项目 / 自然风光 / 文化历史 / 休闲
  features VARCHAR(255),                 -- 特色一句话，逗号分隔关键词：如 网红机位,夜景
  intensity TINYINT NOT NULL DEFAULT 3,  -- 游玩强度 1~5（5 最累）
  suggest_hours DECIMAL(3,1) NOT NULL DEFAULT 2.0,  -- 建议游玩时长（小时）
  ticket_price DECIMAL(10,2) NOT NULL DEFAULT 0,    -- 门票
  lng DECIMAL(10,6) NOT NULL,            -- 经度
  lat DECIMAL(10,6) NOT NULL,            -- 纬度
  rating DECIMAL(2,1) NOT NULL DEFAULT 4.5,
  open_time VARCHAR(64),                 -- 开放时间描述，如 08:00-17:30
  indoor TINYINT NOT NULL DEFAULT 0,     -- 1=室内 0=室外（雨天建议引用）
  status TINYINT NOT NULL DEFAULT 1,
  KEY idx_dest (destination_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### t_restaurant 美食店铺
```sql
CREATE TABLE t_restaurant (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  destination_id BIGINT NOT NULL,
  name VARCHAR(128) NOT NULL,
  cuisine VARCHAR(32) NOT NULL,          -- 风味：本帮菜/川菜/粤菜/火锅/小吃/西餐…
  signature_dish VARCHAR(255),           -- 招牌菜，逗号分隔
  avg_price DECIMAL(10,2) NOT NULL,      -- 人均（元）
  lng DECIMAL(10,6) NOT NULL,
  lat DECIMAL(10,6) NOT NULL,
  rating DECIMAL(2,1) NOT NULL DEFAULT 4.5,
  business_hours VARCHAR(64),            -- 营业时间
  status TINYINT NOT NULL DEFAULT 1,
  KEY idx_dest (destination_id),
  KEY idx_cuisine (cuisine)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### t_hotel 酒店
```sql
CREATE TABLE t_hotel (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  destination_id BIGINT NOT NULL,
  name VARCHAR(128) NOT NULL,
  price_per_night DECIMAL(10,2) NOT NULL,  -- 每晚价格
  rating DECIMAL(2,1) NOT NULL DEFAULT 4.5,
  level VARCHAR(16) NOT NULL DEFAULT '舒适',  -- 经济/舒适/高档/豪华
  lng DECIMAL(10,6) NOT NULL,
  lat DECIMAL(10,6) NOT NULL,
  features VARCHAR(255),                 -- 近地铁,安静,亲子,湖景…
  status TINYINT NOT NULL DEFAULT 1,
  KEY idx_dest (destination_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### t_itinerary 行程（最终结果落库）
```sql
CREATE TABLE t_itinerary (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT NOT NULL,               -- 沿用 JWT 用户（当前内存用户 admin/analyst）
  destination_id BIGINT NOT NULL,
  title VARCHAR(128),                    -- 如 杭州3天2晚攻略
  days INT NOT NULL,                     -- 游玩天数
  total_budget DECIMAL(10,2),            -- 总预算
  total_cost DECIMAL(10,2),              -- 规划预计总消费
  preference_json TEXT,                  -- 用户偏好快照
  plan_json TEXT,                        -- 每日节点 JSON（前端时间线 + 超链接渲染）
  status VARCHAR(16) NOT NULL DEFAULT 'ACTIVE',
  version INT NOT NULL DEFAULT 1,        -- 修改版本号（ADJUST 模式 +1）
  parent_id BIGINT,                      -- 上一版本 itinerary_id（首版为空）
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_user (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### t_itinerary_feedback 行程评价（反馈体系）
```sql
CREATE TABLE t_itinerary_feedback (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  itinerary_id BIGINT NOT NULL,
  user_id BIGINT NOT NULL,
  rating TINYINT NOT NULL,               -- 综合评分 1~5
  pace_rating TINYINT,                   -- 节奏：1太赶 3刚好 5太松
  attraction_satisfy TINYINT,            -- 景点满意度 1~5
  food_satisfy TINYINT,                  -- 美食满意度 1~5
  hotel_satisfy TINYINT,                 -- 酒店满意度 1~5
  budget_fit VARCHAR(16),                -- 超支/刚好/富余
  tags VARCHAR(255),                     -- 快捷标签，逗号分隔：太赶了,想换酒店…
  comment VARCHAR(512),                  -- 文字评论
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_itinerary (itinerary_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### plan_json 结构（约定）
```json
{
  "days": [
    {
      "dayIndex": 1,
      "theme": "抵达 + 西湖夜景",
      "fatigueScore": 6.5,
      "estimatedCost": 860,
      "nodes": [
        {"seq":1, "type":"transport", "name":"萧山机场", "placeId":null, "time":"10:00", "note":"抵达"},
        {"seq":2, "type":"hotel", "placeId":101, "name":"xx酒店", "time":"11:30", "note":"放行李"},
        {"seq":3, "type":"restaurant", "placeId":201, "name":"xx餐厅", "time":"12:00", "note":"午餐"},
        {"seq":4, "type":"attraction", "placeId":301, "name":"断桥残雪", "time":"14:00", "note":"打卡拍照"},
        {"seq":5, "type":"rest", "placeId":305, "name":"湖畔茶馆", "time":"16:30", "note":"休息点"},
        {"seq":6, "type":"hotel", "placeId":101, "name":"xx酒店", "time":"21:00", "note":"休息"}
      ]
    }

```
> 前端根据 `placeId` + `type` 渲染超链接；点击第 N 个节点 → 请求「第 N-1 个节点 → 第 N 个节点」的路径。

## 2. Redis 会话键设计

| Key | 类型 | 内容 | TTL |
|---|---|---|---|
| `travel:session:{sessionId}` | Hash/JSON String | 状态机字段（stage、destination、preference、各级候选集、已选 ids） | 2h |
| `travel:itinerary:{sessionId}` | String(JSON) | 生成中的行程（流式完成后转存 MySQL） | 2h |

> 会话中间态只存 Redis，**最终行程落 MySQL**；Redis 不可用时（旧项目同款风险）问询/规划降级为单轮不记忆，并提示。

## 3. 坐标体系

- 全部地点使用 `lng/lat`（GCJ-02 火星坐标，与国内地图一致，便于未来接高德）。
- 种子数据用真实城市坐标（如杭州西湖 lng 120.15, lat 30.25 附近），实现「就近酒店」「两点路径估算」。
- 距离计算：Haversine 公式（球面距离），封装 `GeoUtils.distanceKm(lng1,lat1,lng2,lat2)`。

## 4. 种子数据规划（实施阶段造数）

| 城市 | 景点 | 美食店 | 酒店 | 覆盖要点 |
|---|---|---|---|---|
| 南京 | 18（打卡/娱乐/自然/休闲/室内各若干，强度 1~5，indoor 标注） | 14（淮扬菜/小吃/火锅 ≥4 风味） | 10（经济~豪华，价格梯度） | **首期演示城市** |
| 苏州 | 18 | 14 | 10 | **首期第二城** |
| 杭州/北京/上海 | — | — | — | 小范围跑通、反馈迭代后再按需扩容 |

要求：每个景点有真实感的中文名、特色、门票、建议时长、强度；每个店铺有风味、人均、招牌菜；每个酒店有价格/评分/档次/坐标。中文用 UNHEX 十六进制写入（沿用旧项目防乱码方案）。

## 5. 表与旧库的共存

- 旧库 `data_agent` 中的 `orders/products/returns/schema_knowledge` 等表**保留不动**（数据库环境不修改）；新表前缀 `t_` 区分。
- 业务数据源只用 `app`（读写）；`bi_readonly` 账号保留在库中但本项目不再使用（已删除只读数据源配置）。
