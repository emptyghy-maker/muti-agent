# 06 前端设计

> 沿用：Vue 3 + Vite、登录骨架（App.vue）、`/api` 代理、JWT 存储与退出逻辑。
> 新增：vue-router（页面路由）、会话状态管理（本阶段用组件内状态 + 简单 store 即可）。

## 1. 页面与路由

| 路由 | 页面 | 说明 |
|---|---|---|
| `/login` | 登录页 | 沿用现有骨架 |
| `/` 或 `/home` | 首页 | 目的地卡片选择（城市+简介+标签） |
| `/plan/:sessionId` | 规划主流程页 | 问询对话 + 候选确认 + 行程时间线，单页内切换步骤 |
| `/plan/:sessionId/route` | （弹层，非独立路由） | 路径详情弹层 |
| `/itineraries` | 我的行程列表 | 历史行程（DB 加载，刷新不丢） |
| `/itinerary/:id` | 行程详情 | 文本/时间线 + 修改入口 + 评价入口 |

导航：登录后进入首页；开始规划后进入主流程页；头部显示用户名 + 退出。

## 2. 主流程页交互设计（核心）

### 步骤条（会话状态机可视化）
```
①偏好问询 → ②景点候选 → ③美食候选 → ④酒店候选 → ⑤行程生成
```
- 根据后端返回的 `stage` 高亮当前步骤，支持点击回到已完成的步骤修改确认。

### ① 偏好问询
- 首轮：开场白 + 引导提示词（「如：想去哪里玩、规划几天旅途、预算范围」），用户**自由输入**。
- 后续轮次：后端 `question.options` 渲染为**单选/多选按钮**（点一下即回答，不逼打字）；同时保留自由输入框。
- 「已收集偏好」摘要卡片：天数、预算、人数、景点/美食/酒店偏好，实时更新（后端返回 `preference` JSON，含「已默认」标记）。

### ②③④ 候选确认（卡片组）
- 景点候选：卡片列表，每张卡片 = 名称 + 特色 + 「为什么推荐」；勾选（可多选）后点「确认」。
- 美食候选：按风味分组展示（分组标题 = 风味，组内 = 店铺名 + 人均 + 招牌菜），组内勾选。
- 酒店候选：卡片 = 名称 + **金额** + **评分**（评分用星级展示）+ 距选中景点中心的距离 + 推荐理由；单选或按人数多选（多晚可同店）。
- 公共交互：底部「确认」「换一批」（调 confirm 接口带 `action=regenerate`）。

### ⑤ 行程生成与展示
- 生成过程：显示「正在规划行程…」，`itinerary_delta` 文本**流式渲染**（Markdown 风格，逐段追加）。
- 生成完成：切换到**行程时间线视图**（结构化 `plan` 驱动）：
  - 顶部 Tab：第一天 / 第二天 / 第三天…
  - 每天一列时间线：时间 + 节点类型图标（✈️交通/🏨酒店/📷景点/🍜餐厅/☕休息）+ 名称 + 说明 + 预计消费合计。
  - 全程总计与预算对比：超支时红色提示 + 调整建议展示。
- 「文本视图 / 时间线视图」切换按钮。
- **天气提醒**：后端返回 `weatherTip`，以浅色提示条展示在行程顶部。
- **修改入口**：「调整行程」按钮 → 弹出输入框（「第二天太赶，删一个景点」）→ 调 adjust 接口 → 生成新版本并展示。

### ⑥ 路径弹层（超链接）
- **行程文本视图**里，所有地点自动识别为**超链接**（按 `[名称]` 或节点渲染时套 `<a>`）。
- **时间线视图**里，每个节点可点击。
- 点击行为：调用 `GET /api/v1/travel/route?sessionId=&fromNodeSeq=&toNodeSeq=`，弹层展示：
  - 起点 → 终点、距离；
  - 方案列表（步行/公交/打车：方式、耗时、费用、步骤文本），默认展开推荐方案。

### ⑦ 我的行程 / 修改 / 评价
- **我的行程**：导航入口 → 行程列表页（目的地/天数/总消费/版本/日期）→ 点击进详情（按 itineraryId 从 DB 加载，刷新/重进不丢）。
- **修改（ADJUST）**：详情页「调整行程」→ 输入诉求 → 新版本展示；可切换查看历史版本（version/parentId 链）。
- **评价**：详情页底部「评价」面板：综合星级 + 节奏/景点/美食/酒店分维度评分 + 快捷标签（太赶了/想换酒店…）+ 评论框 → 提交 feedback 接口。

## 3. 组件划分

```
src/
  router/index.js
  api/http.js                # fetch 封装：注入 token；SSE 封装（token 走 query）
  store/session.js           # 简单响应式 store：sessionId/stage/preference/candidates/plan
  views/
    LoginView.vue            # 沿用骨架改造
    HomeView.vue             # 目的地选择（首期：南京、苏州）
    PlanView.vue             # 主流程容器（步骤条 + 各步骤组件）
    ItineraryListView.vue    # 我的行程列表
    ItineraryDetailView.vue  # 行程详情（含修改/评价入口）
  components/
    PreferenceChat.vue       # ① 问询对话 + 偏好摘要
    CandidateList.vue        # ②③ 通用候选卡片（景点/美食/酒店复用一个组件，props 区分字段）
    FoodCandidateList.vue     # ③ 风味分组变体
    ItineraryTimeline.vue    # ⑤ 时间线视图
    ItineraryText.vue        # ⑤ 文本视图（地点超链接）
    RouteDialog.vue          # ⑥ 路径弹层
    FeedbackPanel.vue        # ⑦ 评价面板（星级/分维度/标签/评论）
    StarRating.vue           # 评分星级
```

## 4. SSE 处理（沿用旧项目模式）

- `EventSource` 不能带 header → token 走 query 参数。
- 事件分发：`stage` 更新步骤条、`preference` 更新偏好摘要、`candidates` 渲染候选、`itinerary_delta` 追加文本、`itinerary` 切换时间线、`done/error` 收尾。
- 断线重连：沿用旧项目「loading 态下 onerror 提示 token 过期/连接中断」。

## 5. 视觉与体验要求

- 城市卡片：城市名 + 一句介绍 + 标签（美食/自然/人文）。
- 全程围绕「轻松可读」：行程文本用 markdown 渲染，超链接蓝色下划线，地点名可点。
- 预计消费：每天底部一行灰字，全程顶部汇总徽章；超支红色。
- 移动端不强制适配（本阶段桌面优先）。
