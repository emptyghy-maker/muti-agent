# Observability 基线快照（DEV-01）

记录日期：2026-09-13。

## 现状基线（开工时）

- 后端：Spring Boot 3.3.5 / MyBatis-Plus 3.5.9 / JDK 21，包根 `com.ghy.mutiagent`，mapper 由启动类 `@MapperScan("com.ghy.mutiagent.repository.mapper")` 注册。
- 追踪：TraceService（内存环形缓冲 200 条）+ TraceContext（S12 冻结终态/分层状态）+ TraceRegistry + TraceView/Redactor。
- 用量：UsageService.record* 系列 + t_usage_record；费用由 ModelPricing.estimate 实时估算（不落库），成本不持久化。
- 评测：service/eval 包（数据集/判据/成对实验/决策/版本管理/反馈闭环）+ service/metrics.MetricsCalculator。
- 操作账本：t_travel_operation / t_travel_session_state（S06-B/S11），TravelOperationService 生命周期（RUNNING→VALIDATED→COMPLETED/FAILED/…）。
- 前端：Vue 3 + Vite，App.vue 自研 hash 路由（前缀匹配），全局 style.css，无路由库/无 UI 库。
- 数据库：MySQL 8.0.46（192.168.150.105 docker da-mysql），业务库 data_agent；门禁隔离库随跑随删。
