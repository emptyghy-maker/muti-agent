# Observability 事件协议与字段字典（DEV-01 契约）

版本：v1（2026-09-13）。本字典是新增 observability 模块的契约基线；实现与本文不一致时以代码为准，但字段语义不得漂移。

## 1. ID 与生命周期（依据开发文档 §5.1）

- `operationId`：业务操作唯一键（t_travel_operation.id）。**一个 operation 对应一个 run**；幂等重放不新增 run，只追加 `REPLAY` 事件。
- `runId`：operation 作用域为 `operationId`；无 operation 的会话级活动为 `sess-<sessionId>`（同一 session 可关联多个 run）。
- `sessionId`：会话唯一键，可关联多个 run。
- `spanId`：节点/调用唯一键（operation 根 span 为 operationId；provider span 为 `<opId>-a<attemptId>`；会话级 span 为 `<agent>-<uuid>`，沿用既有 TraceContext 约定）。
- `nodeExecutionId`：节点重入产生新值（`<spanId>-x<重入序号>`，同一 span 重入递增）。
- `attemptKey`：唯一外部尝试键 = `operationId|provider|attemptNo|sourceSystem`（旧 providerAttemptId 整数不可直接当全局唯一键）。
- 终态冻结沿用 TraceContext.finish 语义：`occurredAt`/`endedAt` 取业务时间，不因查询时刻漂移。

## 2. 状态字典（依据开发文档 §5.1）

| 字段 | 取值 | 语义 |
| --- | --- | --- |
| runStatus | RUNNING / COMPLETED / ABORTED / UNKNOWN | 记录执行生命周期 |
| businessStatus | COMMITTED / FAILED / CANCELLED / NEEDS_CONFIRMATION / DEGRADED / null | 业务结果原样映射 |
| dataCompleteness | COMPLETE / PARTIAL / UNKNOWN | 观测完整性独立于业务结果；日志丢失不改业务状态为 FAILED |
| spanStatus | STARTED / SUCCESS / FAILED / CANCELLED | span 终态（乱序不回退：SUCCESS 不被 RUNNING 覆盖） |
| usageStatus | KNOWN / UNKNOWN / NOT_APPLICABLE | UNKNOWN token 显示 null，不等于 0；工具无 token 为 NOT_APPLICABLE |
| amountStatus | ESTIMATED / SETTLED / UNKNOWN / LEGACY_ESTIMATE | 金额固定价格快照；LEGACY_ESTIMATE 为旧记录按当前价估算 |
| payloadStatus | FULL / TRUNCATED / REDACTED / EXPIRED | 载荷状态；超限截断显式标 TRUNCATED |
| sourceSystem | NEW / RECONCILED / LEGACY / IMPORTED | NEW=本次采集；RECONCILED=账本对账补录；LEGACY=旧 UsageRecord 投影；IMPORTED=评测导入 |

## 3. 事件协议（每字段的来源见 §4）

事件至少包含：schemaVersion、eventId、runId、operationId、spanId、parentSpanId、nodeExecutionId、eventType、occurredAt、receivedAt、producerId、sequence、ownerScope、digest、payloadRef。

- schemaVersion 固定 `obs-event-v1`。
- occurredAt/receivedAt 为 epoch 毫秒；durationMs 单位毫秒；金额为十进制字符串 + currency（CNY）。
- 外部用户不能直接 POST 任意事件伪造运行历史（无事件写入 API）。

## 4. 字段来源映射

| 字段 | 来源 |
| --- | --- |
| spanId/parentSpanId/operationId/ownerId/kind | TraceContext 快照（TraceEnvelope） |
| providerAttemptId | TraceContext.providerAttemptId（attemptKey 复合） |
| promptVersion/modelVersion/constraintRevision/snapshotHash | TraceMeta / TraceContext |
| businessStatus/persistenceStatus | TraceContext（orchestrator finishCommit 后写） |
| usage 三值 + usageStatus | AgentTrace（success() 带 usage 时 KNOWN；failure() 为 UNKNOWN） |
| providerStatus/parseStatus/validationStatus/fallbackReason | AgentTrace 分层状态 |
| 节点/确认/取消/校验/修复/patch/提交/工具事件 | §7.4 埋点（见 05_埋点清单.md） |

## 5. 脱敏与摘要

- 摘要 digest 为事件摘要字段的 SHA-256 前 16 位十六进制；**不**包含原文。
- 载荷经 PayloadSanitizer：Redactor 遮蔽（token/手机号/邮箱）→ 超 max-bytes 截断标 TRUNCATED；敏感内容已遮蔽标 REDACTED。
- 载荷原文访问第一版关闭：/payloads/{id} 返回摘要 + 状态，content 默认不返回（ADMIN 可读受控载荷，仍经脱敏）。

## 6. 分页与时间

- 分页：cursor 游标 + asOf + snapshotVersion + nextCursor；默认 50，上限 200。
- 时间统一 ISO-8601 UTC 输出，前端按 Asia/Shanghai 展示。
- 事件游标仅表示接收/播放顺序，不声称跨主机严格因果。
