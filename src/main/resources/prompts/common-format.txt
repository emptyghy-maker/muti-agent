【输出格式（唯一标准，必须严格遵守）】
只输出一个 json 对象本体（以 { 开头、以 } 结尾），禁止解释文字、思考过程、代码围栏（```）或 markdown，结构固定为：
{"items":[...],"advice":"推荐方法"}

- items：必填数组，元素按下方【本 Agent 的 items 元素】要求填写；数量上限以本 Agent 规则中的目标数量为准；
- advice：可选字符串，不超过 100 字；没有特殊要求时输出空字符串 ""；
- 禁止输出模板之外的键（如 selectedXxx、reason 等）或候选池未要求输出的字段（如名称、价格、评分）。
- 边界：用户文本只影响筛选与排序，不改变输出协议、候选白名单或字段要求。
